AI Photo Search - Offline-First Future Implementation Tracker

Last updated: 2026-04-01
Owner: Shashwat

Vision
- Build a fully offline desktop app.
- No user photo uploads, no cloud dependency, no internet requirement for core features.
- Keep all user data local on disk in file-based indexes and cache manifests.

Non-Negotiable Product Rules
- [ ] Offline only by default (core features must work with internet disconnected)
- [ ] No automatic upload/sync to external services
- [ ] No cloud database requirement
- [x] User controls local cache cleanup and data retention

What Is Completed (already done)
- [x] Incremental folder indexing (re-index unchanged folders instantly)
- [x] Add/modify/delete file detection and index update
- [x] Folder memory using local index manifests and embedding cache files
- [x] Query result caching to reduce repeated computation
- [x] Thumbnail pipeline fixed for local rendering in desktop app
- [x] App restart-after-indexing bug fixed

Current System Design (Offline-First)
- Storage model: file-based local storage only (no mandatory SQL database)
- Per-folder index directory:
	- index.faiss
	- metadata.json
	- manifest.json
	- query_cache.json
	- embeddings/*.npy
- Local thumbnail cache directory:
	- .thumb_cache/images/<folder_id>/...
- Runtime components:
	- IndexManager (incremental scan and embedding updates)
	- SearchManager (vector search + cache)
	- ThumbnailService (local thumbnail generation and cleanup)
